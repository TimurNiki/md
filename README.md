# Mood Diary [ RU ]

A Flutter application designed to help users track their mood, stress levels, and self-esteem. Mood Diary allows users to record their thoughts and feelings through notes and provides a simple interface to save and review their emotional journey.

## Features

* **How Do You Feel?**: Reflect on your feelings with a prompt to assess your current emotional state.
* **Stress Level Tracking**: Easily rate your stress levels on a scale.
* **Self-Esteem Assessment**: Reflect on your self-esteem with guided prompts.
* **Notes**: Write and save personal notes to capture your daily thoughts.
* **Save Functionality**: Store your entries securely for future reference.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/TimurNiki/md.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd md
   ```

3. **Install dependencies:**

   ```bash
   flutter pub get
   ```

4. **Run the app:**

   ```bash
   flutter run
   ```

## Usage

1. Open the app.
2. Reflect on your feelings with the "How Do You Feel?" prompt.
3. Use the stress level slider to indicate your current stress level.
4. Reflect on your self-esteem and record your thoughts.
5. Write notes to document your feelings or experiences.
6. Tap the save button to keep your entries.
